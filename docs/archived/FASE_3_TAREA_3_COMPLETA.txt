  pip install paddleocr easyocr pytesseract opencv-python numpy

Uso básico:
  from core.jersey_number_detector_improved import JerseyNumberDetectorImproved

  detector = JerseyNumberDetectorImproved(
      confidence_threshold=0.7,
      max_workers=4
  )

  results = detector.detect(
      player_boxes=[[x1, y1, x2, y2], ...],
      frame=cv2_frame,
      parallel=True
  )

  numbers = results['numbers']
  confidences = results['confidences']
  details = results['details']

  stats = detector.get_statistics()

Configuración avanzada:
  - confidence_threshold: Umbral de confianza (0.0-1.0)
  - cache_size: Tamaño de cache (1-10000)
  - max_workers: Workers para paralelización (1-16)
  - use_paddle: Activar PaddleOCR
  - use_easyocr: Activar EasyOCR
  - use_tesseract: Activar Tesseract
