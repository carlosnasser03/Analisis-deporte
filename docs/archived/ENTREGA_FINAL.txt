================================================================================
MÉTODOS IMPLEMENTADOS (6 métodos públicos)
================================================================================

1. validate_distance(distance, position) -> Dict
   Valida distancia recorrida contra benchmark
   Retorna: medida, esperada, varianza, estado, confianza, percentil

2. validate_velocity(velocity, position) -> Dict
   Valida velocidad máxima contra benchmark
   Mismo formato que validate_distance

3. validate_intensity(intensity, position) -> Dict
   Valida intensidad del esfuerzo (0-100%)
   Mismo formato que validate_distance

4. detect_anomalies(player_data) -> List[Dict]
   Detecta anomalías en múltiples métricas
   Retorna: métrica, z-score, severidad, descripción

5. generate_comparison(...) -> PlayerValidation
   Análisis completo de jugador
   Retorna: validación completa con recomendaciones

6. get_performance_percentile(metric, position, metric_type) -> float
   Calcula percentil de una métrica
   Retorna: percentil (0-100)
