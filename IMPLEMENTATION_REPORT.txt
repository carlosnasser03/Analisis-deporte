================================================================================

Estados por Z-Score:

  - ALTO:      1.5 < z_score <= 2.5

  - NORMAL:    -1.5 <= z_score <= 1.5

  - CRÍTICA:   |z_score| > 4.0
  - ALTA:      3.0 < |z_score| <= 4.0
  - MEDIA:     2.5 < |z_score| <= 3.0
