PROBLEMA 1: Tracker.update(detections)
─────────────────────────────────────────
❌ ANTES:
  tracks = self.tracker.update(detections)  # RuntimeError
  Error: update() no acepta parámetros

✅ DESPUÉS:
  self.tracker.track(detections, frame_id=frame_idx)
  active_tracks = self.tracker.get_tracks(min_confidence=0.5)

Archivo: pipeline/integrated_pipeline.py (línea 423-426)
Impacto: Permite procesar frames sin errores de método


PROBLEMA 2: Acceso a distance_analysis
──────────────────────────────────────
❌ ANTES:
  total_distance = distance_analysis.distance.total_distance  # AttributeError
  velocities = distance_analysis.velocity.velocity_per_frame

✅ DESPUÉS:
  total_distance = distance_analysis['distance'].total_distance
  velocities = distance_analysis['velocity'].velocity_per_frame

Razón: analyze_player_trajectory() retorna Dict, no objeto
Archivo: pipeline/integrated_pipeline.py (línea 523-551)
Impacto: Acceso correcto a métricas de distancia y velocidad


PROBLEMA 3: Pasar TrackPoint a Heatmap
─────────────────────────────────────
❌ ANTES:
  heatmap_data = manager.generate_complete_analysis(
      tracks=[t for t in tracks]  # Lista de TrackPoint objects
  )
  Error: TypeError - 'TrackPoint' not subscriptable

✅ DESPUÉS:
  track_positions = [(t.x, t.y) for t in tracks]
  heatmap_data = manager.generate_complete_analysis(
      tracks=track_positions,
      player_id=player_id,
      fps=int(self.config.fps)
  )

Razón: Heatmap espera List[Tuple[float, float]], no List[TrackPoint]
Archivo: pipeline/integrated_pipeline.py (línea 529-534)
Impacto: Genera heatmaps sin errores


PROBLEMA 4: TrackState.class_name no existe
─────────────────────────────────────────────
❌ ANTES:
  def _format_detections(self, tracks: Dict) -> List[Dict]:
      for track_id, track in tracks.items():
          formatted.append({'class': track.class_name})  # AttributeError

✅ DESPUÉS:
  def _format_detections(self, tracks_list: List[Dict]) -> List[Dict]:
      for track_dict in tracks_list:
          formatted.append({
              'id': track_dict['track_id'],
              'team_id': track_dict.get('team_id'),        # ✓ Existe
              'jersey_number': track_dict.get('jersey_number')  # ✓ Existe
          })

TrackState TIENE:    track_id, bbox, confidence, velocity, team_id, jersey_number
TrackState NO TIENE: class_name, position (tiene position_history)

Archivo: pipeline/integrated_pipeline.py (línea 464-486)
Impacto: Extrae información de track sin errores


PROBLEMA 5: IntensityMetrics campos incorrectos
────────────────────────────────────────────────
❌ ANTES:
  'movement_intensity_percent': intensity_metrics.movement_intensity_percent
  'sprints_count': intensity_metrics.sprints_count
  'directional_changes': intensity_metrics.directional_changes

✅ DESPUÉS:
  'movement_intensity_percent': intensity_metrics.active_movement_percentage
  'sprints_count': intensity_metrics.sprint_count
  'directional_changes': intensity_metrics.direction_changes_count

Mapeo correcto:
  movement_intensity_percent  → active_movement_percentage
  sprints_count              → sprint_count
  directional_changes        → direction_changes_count

Archivo: pipeline/integrated_pipeline.py (línea 553-557)
Impacto: Mapea correctamente métricas de intensidad
